# Explore Travel Website

A modern responsive website for a fictional travel agency, featuring tour packages, professional guides, and customer reviews.

## Live Demo
[Open Website](https://jdubas94.github.io/EXPLORE/)

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Transitions)
- JavaScript (Vanilla)
- Libraries: Swiper.js, Slick Slider, RateYo

## Features
- Fully responsive layout for desktop, tablet, and mobile
- Interactive burger menu for mobile navigation
- Modal windows for booking and information
- Multiple image sliders (Swiper + Slick)
- Animated scroll interactions
- Star rating system (RateYo library)
- Clean, semantic HTML with organized structure

## Folder Structure
/css
/js
/images
/index.html

## How to Run Locally
1. Clone the repository:
git clone https://github.com/JDubas94/EXPLORE.git
2. Open `index.html` in your browser
No build tools are required.
